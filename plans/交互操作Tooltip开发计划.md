# 交互操作 Tooltip 开发计划

## 背景

部分操作按钮的名称只能表达动作，不能准确表达作用范围、筛选条件和数据影响。例如 Agent 世界书的 Skill 化操作实际受“角色卡世界书 / 手动选择世界书”范围控制，不能简单理解为扫描当前聊天中的所有世界书。

以后新增或修改此类操作时，不能只依赖按钮名称、面板说明或执行前确认弹窗，需要同时提供可随时查看的 Tooltip。

## 目标

- 让用户在执行前明确知道“处理什么、不处理什么、会修改什么”。
- 统一鼠标悬停、键盘聚焦和移动端点击时的说明体验。
- 避免把“当前 Agent 世界书范围”“当前角色卡绑定范围”“当前聊天全部已激活范围”等概念混用。
- 对危险操作同时保留确认弹窗；Tooltip 不能代替二次确认。

## Tooltip 必须覆盖的信息

出现以下任一情况时，按钮或控件必须提供 Tooltip：

1. **作用范围不完全体现在名称中**
   - 当前 Agent 世界书范围
   - 当前角色卡绑定世界书
   - 手动选择的世界书
   - 当前聊天、当前角色或全局配置

2. **存在隐含筛选条件**
   - 只处理勾选条目
   - 跳过 constant、禁用条目、纪要或内部条目
   - 已存在数据时跳过或覆盖

3. **会修改或清除持久化数据**
   - 删除 Skill 元数据
   - 清空缓存、快照、聊天数据或世界书条目
   - 覆盖模板、预设或当前配置

4. **操作结果容易与相近功能混淆**
   - 清理 Agent 运行状态与清除 Skill 化
   - 关闭 Agent 模式与恢复原世界书条目
   - 当前范围操作与全局操作

## 第一批实施范围

### Agent 世界书

- `对所选 Skill 化`
  - 说明只处理当前 Agent 世界书范围内已勾选且符合条件的条目。
  - 说明范围由“角色卡 / 手动选择”配置决定，并非自动读取当前聊天所有已激活世界书。
  - 说明会跳过 constant、专用召回条目、Agent 内部条目和不满足条件的条目。

- `Skill 全选`
  - 说明只勾选当前列表中可 Skill 化的条目，不包含被过滤或不可处理条目。

- `清除 Skill 化`
  - 说明清除当前 Agent 世界书范围内全部 ACU Skill 元数据，而不是只清除页面勾选项。
  - 说明保留条目名称、正文、关键词和条目本身。

- `清理并初始化`
  - 说明恢复 Agent 临时改写的条目并清空运行快照。
  - 说明保留手动世界书范围、Agent 设置和 Skill 元数据。

- `角色卡 / 手动选择` 范围切换
  - 说明该范围同时影响 Skill 化、清除 Skill 化、Agent 决策候选和接管对象。

## 组件与交互要求

- 新建统一的 `AcuTooltip` 或等价基础组件，不在业务组件中重复实现浮层定位和事件处理。
- 支持鼠标悬停、键盘 `focus`、`Escape` 关闭和移动端点击。
- Tooltip 触发器必须可聚焦，并提供正确的 `aria-describedby` 或等价可访问性关联。
- 文案应直接描述范围和影响，不写“点击这里查看说明”等无效提示。
- Tooltip 不遮挡当前操作按钮，不超出视口，在窄屏上允许自动换行。
- 图标按钮继续使用图标和 Tooltip；文字按钮可在按钮旁增加信息图标，避免超长按钮文本。
- 删除、覆盖、批量清理等危险操作仍需确认弹窗，确认文案与 Tooltip 的范围定义必须一致。

## 实施步骤

1. 盘点 `presentation-v2` 中所有命令按钮、图标按钮、批量操作和清理入口。
2. 按“范围敏感 / 隐含筛选 / 持久化修改 / 易混淆”标记优先级。
3. 实现统一 Tooltip 基础组件及桌面、键盘、移动端交互。
4. 优先接入 Agent 世界书第一批操作。
5. 扩展到数据管理、导入、表格填充、剧情推进、向量索引和开发者工具。
6. 建立文案审查清单，新增按钮在评审时必须说明是否需要 Tooltip。

## 测试与验收

- 单元测试覆盖显示、隐藏、键盘聚焦、`Escape` 和移动端点击。
- 组件测试验证 Agent Tooltip 文案与真实作用范围一致。
- 验证 Tooltips 不改变按钮尺寸，不导致工具栏抖动或文字溢出。
- 验证确认弹窗与 Tooltip 对数据影响的描述一致。
- 使用桌面和移动端视口截图检查浮层定位、遮挡和边界溢出。
- 验收时至少覆盖以下误解：
  - 不再把 Agent 手动范围误认为当前聊天全部世界书。
  - 不再把“对所选 Skill 化”误认为处理全部条目。
  - 不再把“清除 Skill 化”误认为删除世界书条目。
  - 不再把“清理并初始化”误认为清除 Skill 元数据或重置手动范围。

## 完成标准

- Agent 世界书首批入口全部接入统一 Tooltip。
- 高风险和范围敏感操作审计完成，并形成后续实施清单。
- 新增 Tooltip 组件通过可访问性和响应式测试。
- 相关文案与 service 层实际范围、过滤和清理行为保持一致。
